About The Project

Built with Pure Vanilla Web Standards

Searchable is a high-performance listing dashboard built entirely using HTML5, CSS3, and Vanilla JavaScript (ES6+). Designed without heavy framework dependencies, it showcases instant client-side multi-criteria search with debouncing, multi-category AND/OR filtering, dynamic sorting, responsive pagination, accessible modal views, and graceful state handling.

⚡

Debounced Search

250ms debounced queries across titles, descriptions, skills, and keywords with real-time text highlighting.

🎯

Compound Filtering

Logical AND across categories combined with flexible OR within multi-selected values.

♿

A11y Accessible

Keyboard navigation, focus management, ARIA live regions, and escape-key dismissable modals.

📱

Fluid Grid

Fully responsive 1/2/3 column layout tested across mobile, tablet, laptop, and ultra-wide screens.
